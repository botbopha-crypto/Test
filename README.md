# Test

A small practice project for learning the GitHub team workflow.

## Files
- `testing.html` - the demo web page
- `image.svg` - the image shown on the page

## How we work as a team
1. Pull the latest `main`
2. Create a branch for your task
3. Commit and push the branch (never push straight to `main`)
4. Open a Pull Request
5. A teammate approves it, then it gets merged
